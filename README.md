# The Sixth Legend(Project_SWENG)

## 개요
육각 그리드 위에서 진행되는 턴제 TRPG 게임입니다. 주사위를 굴려 포인트를 획득하고, 획득한 포인트를 분배하여 이동, 공격, 상호작용합니다. Photon을 이용하여 멀티플레이를 구현하였습니다. 조작은 직관적인 마우스 클릭 및 게임 내 UI 버튼을 통해 이루어집니다.

- [🎮 itch-io에서 플레이](https://sodaxi.itch.io/tile-adventure)

## 개발환경
- 게임 엔진: Unity 6000.0.58f1
- IDE: Visual Studio Code
- 멀티 플레이: Photon
